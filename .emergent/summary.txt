<product_requirements>
The user initially requested a Wordle-like game called Keyboard with a daily challenge involving five words of varying lengths (4 to 8 letters). The core gameplay includes a start button, a timer, and a daily randomized keyboard on which the user must type all five words in order. The overarching requirement was a beautiful UI/UX, following a design system-first approach using React, FastAPI (backend not heavily utilized for game logic), Tailwind, and Shadcn/UI.

As development progressed, the user requested several enhancements:
-   **Keyboard highlighting removal:** Keyboard keys should not highlight the current word, increasing difficulty.
-   **Word stacking:** Daily words should be stacked vertically for better screen fit.
-   **Visibility on smaller screens:** Ensure all game elements (words, timer, keyboard) are visible without scrolling, especially on laptop/mobile.
-   **PWA capabilities:** Make the web app installable to the home screen for an app-like experience.
-   **iPhone keyboard sizing:** Adjust keyboard keys to match standard iPhone size, then later to be larger and spread out to max screen width.
-   **Hard Mode:** Implement a Hard Mode where the keyboard scrambles after each word.
-   **Viral Growth Features:** Ideas for making the game more fun, addictive, and popular, leading to a request for:
    -   Visual Share Cards
    -   Streaks System
    -   WPM (Words Per Minute) + Accuracy Tracking
    -   Daily Quote Mode
    -   Easy and Insane difficulty levels
</product_requirements>

<key_technical_concepts>

-   **React.js:** Frontend framework for building the user interface.
-   **Tailwind CSS:** Utility-first CSS framework for styling, driven by a semantic design system.
-   **Shadcn/UI:** Component library providing accessible and customizable UI primitives.
-   **HSL Color Format:** Strict adherence to HSL for design tokens to support light/dark modes and maintain consistency.
-   **Progressive Web App (PWA):** Web application installable on devices with offline capabilities.
-   **Git/GitHub:** Version control and repository management.
-   **Vercel:** Cloud platform for static sites and serverless functions, used for deployment.
-   **GoDaddy:** Domain registrar for managing custom domains.
-   **LocalStorage:** Client-side storage used for game state and streak persistence.

</key_technical_concepts>
